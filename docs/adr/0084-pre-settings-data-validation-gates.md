# 設定前先過資料面驗證，整表對帳另關

驗證某一薪資期間時，先跑**資料面驗證**（匯入到齊＋設定前原始數字），再在店員／品項等編成輸入就緒後另跑**整表對帳**（對齊 ADR-0049 那類已命名欄）。兩關不可混：手編表的底薪、抽成、達標、任務獎金、應領，以及可手調的上班時數，都不當資料面的通過條件。

資料面 oracle 用人×欄工作表（八月為 `8月報表-中山.xlsx` 的 `8月`），只比營業額與個人業績；原始時數對手編只記錄差異，對同一批打卡重算必須一致。暱稱字串先對、最小建檔後再對薪資列原始營業額／時數加總。注記只驗匯入形狀與未對上點選可列。可勾步驟見 `.scratch/month-end-salary-compile/data-validation-checklist.md`；通過後再決定是否升成自動化接縫。
